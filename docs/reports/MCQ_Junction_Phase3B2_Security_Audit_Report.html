SEC-FINDING-01: Role Confusion in SECURITY DEFINER Functions

Finding Summary: In PostgreSQL, CURRENT_USER inside a SECURITY DEFINER function evaluates to the owner of the function (postgres). Prior code checked ELSIF CURRENT_USER IN ('postgres', 'service_role'), which always returned TRUE even for anonymous requests, accepting an unauthenticated p_admin_user_id.

Remediation Diff

-- BEFORE (Vulnerable):
ELSIF CURRENT_USER IN ('postgres', 'service_role') THEN
    ELSIF p_admin_user_id IS NOT NULL THEN
        v_actual_caller_id := p_admin_user_id; -- Trusted unauthenticated parameter!

-- AFTER (Hardened):
-- Guard 0.1: Immediate rejection of anonymous callers
IF auth.role() = 'anon' THEN
    RAISE EXCEPTION 'MCQJ-ERR-5015: Unauthorized: Anonymous callers cannot execute publication procedure';
END IF;

-- Guard 0.2: PostgREST JWT session
IF auth.uid() IS NOT NULL THEN
    v_actual_caller_id := auth.uid();
    IF p_admin_user_id IS NOT NULL AND p_admin_user_id <> v_actual_caller_id THEN
        RAISE EXCEPTION 'MCQJ-ERR-5015: Caller identity mismatch: authenticated user cannot spoof administrator';
    END IF;

-- Guard 0.3: Authenticated web session missing JWT claim
ELSIF auth.role() = 'authenticated' THEN
    RAISE EXCEPTION 'MCQJ-ERR-5015: Unauthorized: Authenticated web session missing cryptographic user identity';

-- Guard 0.4: Trusted Backend Direct Connection (uses SESSION_USER, not CURRENT_USER)
ELSIF SESSION_USER IN ('postgres', 'service_role') AND auth.role() IS NULL THEN
    IF p_admin_user_id IS NOT NULL THEN
        v_actual_caller_id := p_admin_user_id;
    ELSE
        RAISE EXCEPTION 'MCQJ-ERR-5015: Unauthorized: Missing administrator identity in trusted backend execution';
    END IF;

ELSE
    RAISE EXCEPTION 'MCQJ-ERR-5015: Unauthorized: Missing authenticated session context';
END IF;

SEC-FINDING-02: Option Mapping Alternate Write Paths

Finding Summary: While direct inserts into booklet_option_mappings were protected, parent updates on booklet_question_mappings.occurrence_id or question_options.representation_id could silently desynchronize option mappings from their occurrence.

Remediation: Added triggers trg_booklet_qmap_occurrence_guard (MCQJ-ERR-4008) and trg_question_option_rep_guard (MCQJ-ERR-4009) to reject parent occurrence alterations while option mappings exist.
