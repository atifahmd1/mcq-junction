4. Confirmed Security Defects & Hardening Fixes

Defect SEC-01: SECURITY DEFINER Search Path Hijacking

Vulnerability: Stored procedures running as SECURITY DEFINER without an explicit search_path can be hijacked by malicious objects created in public schemas.

Remediation: Added SET search_path = public, pg_temp; to fn_publish_exam_paper(), fn_guard_published_content_immutability(), and fn_reevaluate_paper_attempts().

Defect SEC-02: Caller Spoofing in Publication Procedure

Vulnerability: fn_publish_exam_paper() previously accepted p_admin_user_id without validating the user's role against the database.

Remediation: Added Gate 0 inside the procedure: 

-- Gate 0: Verify caller ADMIN authorization
SELECT role INTO v_caller_role FROM "users" WHERE id = p_admin_user_id;
IF v_caller_role IS NULL OR v_caller_role <> 'ADMIN' THEN
    RAISE EXCEPTION 'MCQJ-ERR-5015: Unauthorized: Caller does not possess ADMIN role (user_id: %)', p_admin_user_id;
END IF;

Defect SEC-03: Default Public Execution Privileges

Remediation: Revoked public access and restricted execution to authorized database roles: 

REVOKE ALL ON FUNCTION fn_publish_exam_paper(UUID, UUID) FROM PUBLIC;
GRANT EXECUTE ON FUNCTION fn_publish_exam_paper(UUID, UUID) TO authenticated, service_role;

6. Atomic Publication Gate & Concurrency Architecture

Publication requires passing 12 atomic gates under a session-level advisory lock (pg_advisory_xact_lock(hashtext('publish_paper_' || p_paper_id::text))):

  • Gate 0: Verifies caller possesses role = 'ADMIN' in users table.
  • Gate 1: Session advisory lock acquisition preventing concurrent race conditions.
  • Gate 2: Verifies paper is in EDITORIAL_REVIEW or VERIFIED state.
  • Gate 3: Confirms baseline PaperMarkingScheme exists.
  • Gate 4: Verifies sum of section questions equals paper total.
  • Gate 5: Confirms occurrence count equals total questions and sequences are contiguous ($1..N$).
  • Gate 6: Verifies 100% of question representations are editorial_verified = TRUE.
  • Gate 7: Verifies comprehension child questions have valid linked passages.
  • Gate 8: Confirms designated master booklet exists.
  • Gate 9: Verifies master booklet question mappings cover 100% of occurrences.
  • Gate 10: Verifies active official answer key covers 100% of occurrences.
  • Gate 11: Verifies question-type target compatibility (single choice cardinality = 1, etc.).
  • Commit: Sets publish_status = 'PUBLISHED' and timestamps atomically.
