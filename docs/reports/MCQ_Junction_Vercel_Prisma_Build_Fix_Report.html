MCQ Junction — Vercel Production Build Fix: Prisma Enums Generation

Document ID: MCQJ-REPORT-BUILD-PRISMA-ENUMS-01 Date: October 20, 2026 Scope: Vercel Staging CI/CD & Build Invariants

1. Executive Summary & Problem Diagnosis

The Vercel production build for MCQ Junction halted during npm run build with a fatal module resolution error: 

Import map: aliased to relative './src/generated/prisma/enums'
Error: [BUILD_UTILS_SPAWN_1] Command "npm run build" exited with 1

The stack trace pointed directly to ExamEntryPageProps in src/app/exam/[paperId]/page.tsx.

Root Cause: prisma/schema.prisma outputs the generated client to ../src/generated/prisma, which is excluded from Git tracking via .gitignore. In Vercel's clean build environment, src/generated/prisma/ does not exist upon clone. Because package.json previously defined "build": "next build" without running prisma generate, Next.js 16 (Turbopack) attempted to compile TypeScript routes referencing @/generated/prisma/enums before the file was generated.

5. Permanent Deployment Invariants

  • Generated Files Excluded: src/generated/prisma remains ignored in .gitignore. No ephemeral build artifacts are committed to Git.
  • Deterministic Pipeline: "build": "prisma generate && next build" guarantees that every CI/CD runner generates typed Prisma Client code prior to compilation.
  • Database Independent: prisma generate generates client types purely from prisma/schema.prisma and does not require an active database connection or credentials during build phase.
