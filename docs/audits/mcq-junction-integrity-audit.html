2. Concrete Defects Fixed from v3.2/v3.3 & Structural Audit

2.1 Identifier Parity Defect (BLK-01)

In v3.2 and v3.3 drafts, trigger procedures and foreign key statements referenced camelCase columns such as learningAttemptLogId, conceptualQuestionId, and paperQuestionOccurrenceId. Because PostgreSQL folds unquoted identifiers to lower-case, queries executed against tables created with quoted identifiers or mapped columns would fail at runtime with column "learningattemptlogid" does not exist.

Fix in v3.4: Every physical database object—tables, columns, constraints, foreign keys, triggers, and enumerations—is strictly declared in standard PostgreSQL snake_case. In Prisma 7, every field has an explicit @map("column_name") and every model has @@map("table_name").

2.2 Trigger Runtime Failure on DELETE (BLK-02)

In PostgreSQL, a BEFORE DELETE trigger function must return OLD to allow deletion or raise an exception to abort. Returning NEW causes PostgreSQL to treat the result as NULL, which silently converts an allowed deletion into a no-op or causes unexpected execution behavior.

Fix in v3.4: All delete trigger functions explicitly RETURN OLD; upon authorization and raise EXCEPTION when violating immutability: 

IF TG_OP = 'DELETE' THEN
    RETURN OLD;
ELSE
    RETURN NEW;
END IF;

2.3 Scope of Immutability Protection (BLK-02)

Previous drafts only protected source_question_representations. An administrator or script could still alter options, delete occurrences, or change marking schemes while a paper was marked PUBLISHED. In v3.4, the immutability trigger suite binds eight interconnected relational tables: exam_papers, paper_sections, paper_question_occurrences, source_question_representations, question_options, comprehension_passages, paper_marking_schemes, and section_scoring_overrides.

2.4 Race Conditions in Publication Gate (BLK-03)

Application-level publication checks were vulnerable to concurrency races. In v3.4, publication is encapsulated in a PostgreSQL stored procedure (fn_publish_exam_paper) that acquires a transaction-scoped advisory lock: 

PERFORM pg_advisory_xact_lock(hashtext('publish_paper_' || p_paper_id::text));

2.5 Preservation of Historical Attempts during Account Erasure (BLK-05)

TestAttempt.user_id is defined as UUID NULL with foreign key action ON DELETE SET NULL. When a user requests account erasure, personal credentials and private bookmarks are deleted, but past test attempts survive with user_id = NULL, preserving historical score distributions and item discrimination metrics.

-- Master Content Immutability Function
CREATE OR REPLACE FUNCTION fn_guard_published_content_immutability()
RETURNS TRIGGER
LANGUAGE plpgsql
AS $$
DECLARE
    v_paper_id UUID;
    v_publish_status paper_publish_status_enum;
BEGIN
    IF TG_TABLE_NAME = 'exam_papers' THEN
        IF TG_OP = 'UPDATE' THEN
            IF OLD.publish_status = 'PUBLISHED' AND NEW.publish_status = 'PUBLISHED' THEN
                IF OLD.paper_code <> NEW.paper_code OR
                   OLD.total_questions <> NEW.total_questions OR
                   OLD.max_score <> NEW.max_score OR
                   OLD.total_duration_minutes <> NEW.total_duration_minutes THEN
                    RAISE EXCEPTION 'MCQJ-ERR-4001: Cannot alter structural attributes of an already PUBLISHED ExamPaper (paper_id: %)', OLD.id;
                END IF;
            END IF;
            RETURN NEW;
        ELSIF TG_OP = 'DELETE' THEN
            IF OLD.publish_status = 'PUBLISHED' THEN
                RAISE EXCEPTION 'MCQJ-ERR-4002: Cannot DELETE a PUBLISHED ExamPaper (paper_id: %)', OLD.id;
            END IF;
            RETURN OLD;
        END IF;
        RETURN NEW;
    END IF;

    -- Map Child Tables to Paper ID
    IF TG_TABLE_NAME = 'paper_sections' THEN
        IF TG_OP = 'DELETE' THEN v_paper_id := OLD.paper_id; ELSE v_paper_id := NEW.paper_id; END IF;
    ELSIF TG_TABLE_NAME = 'paper_question_occurrences' THEN
        IF TG_OP = 'DELETE' THEN v_paper_id := OLD.paper_id; ELSE v_paper_id := NEW.paper_id; END IF;
    ELSIF TG_TABLE_NAME = 'paper_marking_schemes' THEN
        IF TG_OP = 'DELETE' THEN v_paper_id := OLD.paper_id; ELSE v_paper_id := NEW.paper_id; END IF;
    ELSIF TG_TABLE_NAME = 'section_scoring_overrides' THEN
        SELECT s.paper_id INTO v_paper_id FROM paper_sections s WHERE s.id = (CASE WHEN TG_OP = 'DELETE' THEN OLD.section_id ELSE NEW.section_id END);
    ELSIF TG_TABLE_NAME = 'source_question_representations' THEN
        SELECT o.paper_id INTO v_paper_id FROM paper_question_occurrences o WHERE o.id = (CASE WHEN TG_OP = 'DELETE' THEN OLD.occurrence_id ELSE NEW.occurrence_id END);
    ELSIF TG_TABLE_NAME = 'question_options' THEN
        SELECT o.paper_id INTO v_paper_id
        FROM source_question_representations r
        JOIN paper_question_occurrences o ON o.id = r.occurrence_id
        WHERE r.id = (CASE WHEN TG_OP = 'DELETE' THEN OLD.representation_id ELSE NEW.representation_id END);
    ELSIF TG_TABLE_NAME = 'booklet_series' THEN
        IF TG_OP = 'DELETE' THEN v_paper_id := OLD.paper_id; ELSE v_paper_id := NEW.paper_id; END IF;
    ELSIF TG_TABLE_NAME = 'booklet_question_mappings' THEN
        SELECT bs.paper_id INTO v_paper_id FROM booklet_series bs WHERE bs.id = (CASE WHEN TG_OP = 'DELETE' THEN OLD.booklet_series_id ELSE NEW.booklet_series_id END);
    ELSIF TG_TABLE_NAME = 'booklet_option_mappings' THEN
        SELECT bs.paper_id INTO v_paper_id
        FROM booklet_question_mappings bqm
        JOIN booklet_series bs ON bs.id = bqm.booklet_series_id
        WHERE bqm.id = (CASE WHEN TG_OP = 'DELETE' THEN OLD.question_mapping_id ELSE NEW.question_mapping_id END);
    END IF;

    SELECT publish_status INTO v_publish_status FROM exam_papers WHERE id = v_paper_id;

    IF v_publish_status = 'PUBLISHED' THEN
        IF TG_OP = 'INSERT' THEN
            RAISE EXCEPTION 'MCQJ-ERR-4003: Cannot INSERT new records into % under a PUBLISHED ExamPaper (paper_id: %)', TG_TABLE_NAME, v_paper_id;
        ELSIF TG_OP = 'UPDATE' THEN
            RAISE EXCEPTION 'MCQJ-ERR-4004: Cannot UPDATE content in % under a PUBLISHED ExamPaper (paper_id: %)', TG_TABLE_NAME, v_paper_id;
        ELSIF TG_OP = 'DELETE' THEN
            RAISE EXCEPTION 'MCQJ-ERR-4005: Cannot DELETE records from % under a PUBLISHED ExamPaper (paper_id: %)', TG_TABLE_NAME, v_paper_id;
        END IF;
    END IF;

    IF TG_OP = 'DELETE' THEN
        RETURN OLD;
    ELSE
        RETURN NEW;
    END IF;
END;
$$;

6. Publication Gate, Scoring Engine & Re-Evaluation Contracts

6.1 Atomic Publication Gate Specification

The stored procedure fn_publish_exam_paper() enforces 10 strict validation gates under a transactional advisory lock:

  1. Acquires pg_advisory_xact_lock() to prevent concurrent publication attempts.
  2. Validates paper existence and ensures status is not already PUBLISHED.
  3. Confirms baseline PaperMarkingScheme exists.
  4. Verifies sum of section question counts equals total_questions.
  5. Checks occurrences count equals total_questions and verifies sequence numbers are contiguous from 1 to N.
  6. Confirms 100% of source_question_representations have editorial_verified = TRUE.
  7. Ensures exactly one master BookletSeries is designated.
  8. Verifies 100% of occurrences have an ACTIVE official answer key item.
  9. Atomically sets publish_status = 'PUBLISHED'.
  10. Emits structured JSON execution report.

6.2 Mathematical Scoring Engine Precedence Specification

Marks earned ($M_i$) and penalty magnitude ($P_i \ge 0$) follow strict hierarchical inheritance:

Hierarchical Precedence: Occurrence Override ≻ Section Override ≻ Paper Baseline
Evaluation Condition Score Awarded (Δ Score) Denominator Contribution (Δ Denom) Description
Withdrawn (FULL_MARKS_AWARDED) + Mi + Mi Question cancelled; full marks awarded to all candidates.
Withdrawn (EXCLUDED_FROM_TOTAL) 0.000 0.000 Question nullified; deducted from paper total marks.
Correct Answer + Mi + Mi Candidate response strictly matches official answer key.
Incorrect Answer - Pi + Mi Wrong answer; negative penalty deducted from aggregate.
Unanswered / Omitted 0.000 + Mi Candidate skipped question; zero score delta.
