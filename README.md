# MCQ Junction

Incremental MCQ practice platform built with Next.js, TypeScript, and React.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint |
| `npm run typecheck` | Run TypeScript checks |

## Current status

Foundation only: Next.js App Router, TypeScript, Tailwind CSS. Product modules (auth, database, quizzes, admin, AI) are not added yet.
